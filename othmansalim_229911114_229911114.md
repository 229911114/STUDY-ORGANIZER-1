For my part of the project, I built the Task Manager so students can easily track, organize, and manage their homework and assignments right from the terminal.

I created a TaskManager class using Python loops, functions, and error handling. I also integrated it with our team's shared storage.py module to safely read and write data.

My code lets users view tasks, add new ones, mark them complete, and delete them. It also automatically saves everything to our JSON file and re-numbers the task IDs so the list always stays clean.

I also have created a ScheduleManager class with interactive terminal loops and connected it to our shared storage.py module to save everything into a JSON file.

It lets users add study blocks (by day, time, subject, and activity), view their full schedule, delete blocks with automatic re-indexing, and generate schedule summaries.



This ties all our individual team modules together and provides an automated system overview.
